🖥️ Personal Portfolio Website
📌 Overview

    This is a personal portfolio website built using HTML5, CSS3, and Font Awesome icons.
    It showcases a simple, elegant, and responsive layout designed with Flexbox and CSS animations to create a modern and engaging user experience.

    The website introduces Austine Lubanga, a web designer passionate about creating efficient, beautiful, and user-friendly digital solutions.

🚀 Features

🧑‍💻 Profile Section – Displays a profile picture, name, and role.

    🌐 Social Links – Links to Facebook, Instagram, Twitter, and LinkedIn using Font Awesome icons.

    🧾 About Me Section – Highlights skills, background, and professional traits.

    💌 Email Button – Allows visitors to contact via email.

    📱 Responsive Design – Works seamlessly across desktops, tablets, and mobile devices.

✨ Animations – Smooth entry animations, hover effects, and transitions for a dynamic feel.

🛠️ Technologies Used
    Technology	Purpose
    HTML5	Structure and layout of the website
    CSS3 (Flexbox)	Styling, responsiveness, and layout management
    Font Awesome 6.5.0	Social media and iconography
    Google Fonts (optional)	For improved typography (if added later)

⚙️ How to Run the Project

1. Clone or download this repository:
    git clone https://github.com/yourusername/portfolio-website.git
2. Open the project folder:
    cd portfolio-website
3. Run the project:
    Simply open index.html in your web browser.
    Or use a local server (e.g., VS Code Live Server) for best experience.

🖌️ Design Highlights

    The entire layout is managed using Flexbox for perfect alignment and responsiveness.

    The profile picture gently enlarges on hover with a soft glow effect.

    The social icons bounce upward when hovered, adding interactivity.

    Smooth fade-in and slide-in animations make the layout come alive on load.

    The darkslategray accent color ensures good contrast and a professional feel.
